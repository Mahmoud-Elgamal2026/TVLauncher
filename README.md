| | الرابط |

## التثبيت على البوكس
1. نزّل تطبيق **Downloader** على البوكس.
2. اكتب لينك اللانشر فوق ودوس تثبيت.
3. افتح اللانشر واختاره كشاشة رئيسية.

اللانشر بيحدّث نفسه لوحده.
